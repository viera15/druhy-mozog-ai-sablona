# Dashboard projektu

Priečinok `06_dashboard` sústreďuje súbory prehľadu tohto projektu: jeho zdrojové súbory, údaje, spúšťacie súbory a výsledný prehľad. Súvisiace časti môžu byť v podpriečinkoch.

- Dashboard sa vytvára podľa potrieb a schváleného rozsahu projektu. Samotná prítomnosť tohto priečinka neznamená, že už existuje funkčný dashboard.
- Pri vytvorení alebo úprave dashboardu používaj tento priečinok. Ak jeho existujúce súbory alebo priečinok sú uložené inde v tom istom projekte, presuň ich sem v rozsahu schváleného zadania a oprav cesty, odkazy a spúšťanie.
- Pred presunom over konkrétne zdroje, ciele bez kolízie a oprávnenie; po presune skontroluj zachovanie obsahu a funkčnosť dotknutých väzieb. Existujúci dashboard neprepisuj novým.
- Dashboard je prehľad nad projektovými zdrojmi pravdy; nenahrádza `README.md`, `MEMORY.md`, `open_items.md` ani ostatnú evidenciu.
- Spoločný dashboard viacerých projektov a vlastný dashboard konkrétneho projektu majú rozdielny rozsah. Registrácia projektu do spoločného dashboardu nevytvára jeho vlastný dashboard.
