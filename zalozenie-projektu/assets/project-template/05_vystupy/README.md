# Výstupy

Sem patria hotové, skontrolované a schválené výsledky projektu.

Odporúčané členenie podľa potreby:

- dokumenty,
- reporty,
- exporty,
- prezentácie,
- odovzdané verzie.

Pravidlá:

- Pred uložením vykonaj primeranú obsahovú a technickú kontrolu.
- Rozlišuj medzi stavom `uložené` a `uložené a overené`.
- Ak výstup nahrádza staršiu verziu, staršiu verziu archivuj alebo jasne označ.
- Pri odovzdanom výstupe eviduj dátum a verziu.
