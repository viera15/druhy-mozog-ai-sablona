# Inbox

Sem patria nové materiály, ktoré ešte neboli skontrolované a zaradené.

Pravidlá:

- Každú položku v tomto priečinku okrem `README.md` považuj za nový nespracovaný materiál.
- Pri začatí práce v projekte skontroluj obsah priečinka a nájdené položky oznám používateľovi.
- Obsah inboxu nepovažuj automaticky za overený.
- Ak materiál nesúvisí s aktuálnou úlohou, iba naň upozorni a pokračuj v zadanej práci.
- Po spracovaní navrhni jeho cieľové umiestnenie v `01_zdroje`, `02_wiki`, `04_pracovne` alebo `99_archiv`.
- Materiál bez výslovného súhlasu používateľa nepresúvaj, neprepisuj ani nemaž.
- Pri presune zachovaj pôvodný súbor, ak je potrebný ako dôkaz alebo referencia.
- Nespracovaný alebo ešte nezaradený materiál ponechaj v inboxe a uveď ho medzi otvorenými bodmi.
- Cieľom je, aby po spracovaní a schválenom zaradení zostal inbox prázdny okrem `README.md`.

Odporúčaný názov súboru:

```text
RRRR-MM-DD_Zdroj_Strucny-nazov_Typ.ext
```

Príklady:

```text
2026-09-20_KRONE_Test-Analyst_email.pdf
2026-09-20_KRONE_Test-Analyst_priloha.pdf
```
