# Archív

Sem patria nahradené, neaktuálne alebo uzatvorené materiály, ktoré treba zachovať pre históriu.

Odporúčané členenie:

- rozhodnutia,
- otvorené položky,
- zdroje,
- pracovné súbory,
- výstupy.

Pravidlá:

- Archivovaný obsah sa nepovažuje za aktuálny.
- Pri archivácii zachovaj názov, dátum a dôvod presunu.
- Platné informácie musia zostať dostupné v aktívnej časti projektu.
- Archív nepoužívaj ako bežný pracovný priečinok.
