# Pracovné súbory

Sem patria koncepty, rozpracované dokumenty, pomocné analýzy a dočasné výsledky.

Pravidlá:

- Rozpracovaný súbor nepovažuj za schválený výstup.
- V názve podľa potreby uveď dátum alebo označenie konceptu.
- Po schválení presuň výsledok do `05_vystupy`.
- Nepotrebné dočasné súbory pravidelne odstráň alebo archivuj po overení, že už nie sú potrebné.
