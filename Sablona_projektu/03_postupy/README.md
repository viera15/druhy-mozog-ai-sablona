# Opakovateľné postupy

Sem patria pracovné postupy, ktoré sa v projekte opakujú.

Každý postup by mal obsahovať:

- účel,
- potrebné vstupy,
- jednotlivé kroky,
- kontrolné body,
- očakávaný výstup,
- známe výnimky a riziká.

Postup vytvor až po praktickom použití činnosti. Automatizáciu alebo samostatnú schopnosť zvažuj až vtedy, keď je postup stabilný a opakovane overený.
