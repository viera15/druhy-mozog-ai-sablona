# Pôvodné zdroje

Sem patria pôvodné dokumenty, zadania, exporty, tabuľky, PDF, obrázky a ďalšie referenčné materiály.

Pravidlá:

- Pôvodné zdroje bez výslovného pokynu neupravuj.
- Pri odvodenej informácii eviduj, z ktorého zdroja pochádza.
- Ak existuje viac verzií, označ dátum alebo verziu.
- Neaktuálny zdroj nevymazávaj, ale podľa potreby ho presuň do `99_archiv`.
- Citlivé údaje chráň podľa pravidiel v koreňovom `README.md`.
